# Математическое обоснование AMDB

**Доказательства аксиом, теорема о разложении плана, класс представимых
запросов, обобщение на полукольца. Версия 1.0 · 27.08.2026**

Документ закрывает разрыв, выявленный двумя аудитами
([Соколов](Соответствие%20теории%20Соколова.md),
[концепция машины](Соответствие%20концепции%20алгебраической%20машины.md)):
аксиомы системы были объявлены и верифицированы тестами, но не доказаны.
Здесь они доказаны. Тесты остаются проверкой *реализации*, а не обоснованием
*теории*.

---

## 1. Обозначения и определения

Пусть **K** = (K, ⊕, ⊗, 0̄, 1̄) — коммутативное полукольцо: ⊕ и ⊗ ассоциативны
и коммутативны, ⊗ дистрибутивно относительно ⊕, 0̄ — нейтраль ⊕ и
поглощающий элемент ⊗, 1̄ — нейтраль ⊗. Исходная алгебра Соколова —
случай K = (ℝ, +, ·).

**Определение 1 (многомерная матрица).** Пусть I₁, …, I_p — конечные
непустые множества индексов. Многомерной матрицей ранга *p* называется
отображение A: I₁ × … × I_p → K. Множество всех таких матриц обозначим 𝕄.

Мультииндексы обозначаем заглавными: L = (l₁,…,l_k) ∈ I_L = I_{l₁}×…×I_{l_k}.

**Определение 2 ((λ, μ)-свёрнутое произведение).** Пусть

* A: I_L × I_S × I_C → K ранга k + λ + μ,
* B: I_S × I_C × I_M → K ранга λ + μ + v,

где |S| = λ, |C| = μ, а группы I_S и I_C у обоих сомножителей совпадают.
Тогда (λ, μ)-свёрнутое произведение C = A ∗_{λ,μ} B определяется как

> **C_{L,S,M} = ⊕_{C ∈ I_C} A_{L,S,C} ⊗ B_{S,C,M}**

Индексы группы S называем **скоттовыми** (λ-индексы: общие, сохраняются),
группы C — **кэлиевыми** (μ-индексы: общие, свёртываются), групп L и M —
**свободными**. Терминология и сама раскладка согласованы с работой
Мунермана и Мунермана (2022), где определение дано в том же виде
A = a_lsc, B = b_scm, C = c_lsm и приведена та же формула ранга
r = p + q − λ − 2μ (доказывается ниже как A2).

Все суммы ⊕ конечны, поэтому все перестановки и перегруппировки ниже законны
в силу ассоциативности и коммутативности ⊕.

## 2. Доказательства аксиом A1–A9

### A1. Замкнутость 𝕄 относительно ∗

*Утверждение.* C = A ∗_{λ,μ} B ∈ 𝕄, причём C: I_L × I_S × I_M → K.

*Доказательство.* Для каждого фиксированного (L, S, M) выражение
⊕_{C∈I_C} A_{L,S,C} ⊗ B_{S,C,M} — конечная ⊕-сумма элементов K, следовательно
элемент K (замкнутость K относительно ⊗ и ⊕). Значит C — отображение
I_L × I_S × I_M → K, то есть элемент 𝕄. ∎

### A2. Арифметика рангов

*Утверждение.* rank(A ∗_{λ,μ} B) = rank A + rank B − λ − 2μ.

*Доказательство.* По определению rank C = k + λ + v. Так как
k = rank A − λ − μ и v = rank B − λ − μ, получаем
rank C = (rank A − λ − μ) + λ + (rank B − λ − μ) = rank A + rank B − λ − 2μ. ∎

### A3. Билинейность

*Утверждение.* Для любых A, A′ ∈ 𝕄 подходящей формы, B, B′ ∈ 𝕄 и α ∈ K:

1. A ∗ (B ⊕ B′) = (A ∗ B) ⊕ (A ∗ B′);
2. (A ⊕ A′) ∗ B = (A ∗ B) ⊕ (A′ ∗ B);
3. (α ⊗ A) ∗ B = A ∗ (α ⊗ B) = α ⊗ (A ∗ B).

*Доказательство (1).*

```
(A ∗ (B ⊕ B′))_{L,S,M}
  = ⊕_C A_{L,S,C} ⊗ (B_{S,C,M} ⊕ B′_{S,C,M})
  = ⊕_C ( (A ⊗ B) ⊕ (A ⊗ B′) )                       [дистрибутивность ⊗ над ⊕]
  = (⊕_C A ⊗ B) ⊕ (⊕_C A ⊗ B′)                       [ассоц. и коммут. ⊕]
  = (A ∗ B)_{L,S,M} ⊕ (A ∗ B′)_{L,S,M}.
```

Пункт (2) симметричен. Пункт (3): α выносится за ⊕-сумму по дистрибутивности,
а перестановка сомножителей законна по коммутативности ⊗. ∎

*Проверка реализации:* `test_distributive_over_addition`,
`test_homogeneous_in_both_arguments`.

### A4. Ассоциативность

*Утверждение.* Пусть

* A: I_L × I_S × I_{C₁},
* B: I_S × I_{C₁} × I_{C₂},
* D: I_S × I_{C₂} × I_M,

то есть группа I_S выступает λ-группой **в обоих** произведениях. Тогда

> (A ∗_{λ,μ₁} B) ∗_{λ,μ₂} D = A ∗_{λ,μ₁} (B ∗_{λ,μ₂} D).

*Доказательство.*

```
((A ∗ B) ∗ D)_{L,S,M}
  = ⊕_{C₂} ( ⊕_{C₁} A_{L,S,C₁} ⊗ B_{S,C₁,C₂} ) ⊗ D_{S,C₂,M}
  = ⊕_{C₂} ⊕_{C₁} (A ⊗ B) ⊗ D            [правая дистрибутивность]
  = ⊕_{C₁} ⊕_{C₂} A ⊗ (B ⊗ D)            [перестановка конечных ⊕-сумм; ассоц. ⊗]
  = ⊕_{C₁} A_{L,S,C₁} ⊗ ( ⊕_{C₂} B ⊗ D )  [левая дистрибутивность]
  = (A ∗ (B ∗ D))_{L,S,M}.  ∎
```

**Замечание (существенное).** Условие «I_S — λ-группа в обоих произведениях»
опустить нельзя. Если в первом произведении S свёртывается (становится
μ-группой), равенство теряет смысл уже по форме результата: при
|L|=2, |S|=3, |C|=4, |M|=5, |N|=2 выражение с S = λ даёт матрицу формы
(2, 3, 2), а с S = μ в первом произведении — форму (2, 2), и даже после
свёртки первой по S значения не совпадают (проверено:
`test_associativity_fails_when_lambda_axis_is_dropped_midway`).

Отсюда требование к оптимизатору: переставляя порядок свёрток, он обязан
сохранять **роли** индексов, а не только их имена. Реализация это соблюдает —
`binary_decomposition` пересчитывает роли на каждом шаге.

### A5. Некоммутативность

*Утверждение.* ∗_{λ,μ} в общем случае не коммутативна.

*Доказательство.* Достаточно контрпримера. При λ=0, μ=1 и K = (ℝ, +, ·)
возьмём

```
A = [0 1]      B = [0 0]
    [0 0]          [1 0]

A ∗ B = [1 0]      B ∗ A = [0 0]
        [0 0]              [0 1]
```

Более того, при |I_L| ≠ |I_M| произведение B ∗ A вообще не определено. ∎

### A6. Единичный элемент

*Утверждение.* Пусть I_M = I_C (совпадающие множества индексов) и

> E_{S,C,M} = 1̄, если C = M, и 0̄ иначе

(δ-матрица по μ-группе, не зависящая от λ-индексов). Тогда A ∗_{λ,μ} E = A.

*Доказательство.*

```
(A ∗ E)_{L,S,M} = ⊕_C A_{L,S,C} ⊗ E_{S,C,M}
                = (A_{L,S,M} ⊗ 1̄) ⊕ ( ⊕_{C≠M} A_{L,S,C} ⊗ 0̄ )
                = A_{L,S,M} ⊕ 0̄  =  A_{L,S,M}.  ∎
```

Использованы аксиомы полукольца: x ⊗ 1̄ = x, x ⊗ 0̄ = 0̄, x ⊕ 0̄ = x.
При λ = 0, μ = 1 и ранге 2 это обычная единичная матрица.

*Реализация:* `amdb.core.unit_matrix`; проверка `test_right_unit_for_mu_one/two`.

### A7. Нулевой элемент

*Утверждение.* A ∗_{λ,μ} 0̄ = 0̄ и A ⊕ 0̄ = A.

*Доказательство.* (A ∗ 0̄)_{L,S,M} = ⊕_C A_{L,S,C} ⊗ 0̄ = ⊕_C 0̄ = 0̄
(поглощение и нейтральность 0̄). Второе — по определению нейтрали ⊕. ∎

### A8. Закон транспонирования

*Определение 3 (транспонирование по группам).* Для A: I_L × I_S × I_C положим
A^T: I_S × I_C × I_L, (A^T)_{S,C,L} = A_{L,S,C}; аналогично
(B^T)_{M,S,C} = B_{S,C,M} и (C^T)_{M,S,L} = C_{L,S,M}.

*Утверждение.* (A ∗_{λ,μ} B)^T = B^T ∗_{λ,μ} A^T.

*Доказательство.*

```
(B^T ∗ A^T)_{M,S,L} = ⊕_C (B^T)_{M,S,C} ⊗ (A^T)_{S,C,L}
                    = ⊕_C B_{S,C,M} ⊗ A_{L,S,C}
                    = ⊕_C A_{L,S,C} ⊗ B_{S,C,M}      [коммутативность ⊗]
                    = (A ∗ B)_{L,S,M} = ((A ∗ B)^T)_{M,S,L}.  ∎
```

**Существенное условие: ⊗ коммутативна.** Над некоммутативным полукольцом
закон в этой форме неверен.

### A9. Вырождение в известные операции

Все пункты — прямая подстановка в определение 2.

| λ | μ | Результат | Обоснование |
|---|---|---|---|
| 0 | 0 | C_{L,M} = A_L ⊗ B_M — тензорное (внешнее) произведение | ⊕ по пустой группе индексов есть один член |
| 0 | 1, ранги 2 | C_{lm} = ⊕_c A_{lc} ⊗ B_{cm} — умножение матриц | определение при k=v=1 |
| 0 | μ | свёртка по μ осям (`tensordot`) | определение при λ=0 |
| λ | 0 | C_{L,S,M} = A_{L,S} ⊗ B_{S,M} | ⊕ по пустой μ-группе |

*Проверка:* `test_reduces_to_outer_product`,
`test_reduces_to_matrix_multiplication`, `test_reduces_to_tensordot`,
`test_lambda_only_product_keeps_shared_axis`.

## 3. Теорема о разложении плана

Это математическое содержание тезиса «программа есть терм, а оптимизация —
переписывание терма».

**Определение 4 (многооперандное стягивание).** Пусть X — конечное множество
имён индексов, каждому x ∈ X сопоставлено конечное I_x. Пусть матрицы
A₁, …, A_n индексированы наборами X₁, …, X_n ⊆ X, и задан выходной набор
O ⊆ ⋃X_i. Положим

> F_O(A₁,…,A_n)_{O} = ⊕_{значения индексов из (⋃X_i) ∖ O} ⊗_{i=1..n} A_i

(сумма произведений по всем наборам значений невыходных индексов).

**Определение 5 (план).** Планом называется двоичное дерево p с листьями
A₁,…,A_n. Вычисление ev_p идёт снизу вверх: во внутреннем узле, объединяющем
поддеревья с наборами операндов P и Q, берётся (λ, μ)-произведение их
результатов, где

* μ-группа — общие индексы P и Q, не входящие ни в O, ни в наборы операндов,
  оставшихся вне P ∪ Q;
* λ-группа — прочие общие индексы;

после чего индексы результата, не входящие ни в O, ни в оставшиеся операнды,
свёртываются (0, μ)-произведением с матрицей из 1̄.

**Теорема 1.** Для любого плана p выполняется ev_p = F_O.

*Доказательство.* Индукция по n.

*База* n = 1: единственная операция — свёртка невыходных индексов с матрицей
единиц, что совпадает с F_O по определению.

*Лемма (вынесение суммы).* Если индекс x встречается только в множителе f,
то ⊕_x (f ⊗ g) = (⊕_x f) ⊗ g. Это правая дистрибутивность ⊗ над конечной
⊕-суммой.

*Шаг.* Пусть корень дерева объединяет поддеревья с операндами P и Q,
P ⊔ Q = {1..n}. Разобьём невыходные индексы на три класса: встречающиеся
только в P, только в Q, и общие. Тогда

```
F_O = ⊕_{общие} ⊕_{только P} ⊕_{только Q}  (⊗_{i∈P} A_i) ⊗ (⊗_{j∈Q} A_j)
    = ⊕_{общие} ( ⊕_{только P} ⊗_{i∈P} A_i ) ⊗ ( ⊕_{только Q} ⊗_{j∈Q} A_j )
```

— перегруппировка законна по ассоциативности и коммутативности ⊕ (все суммы
конечны), а вынесение внутренних сумм — по лемме, поскольку индексы класса
«только P» не встречаются в множителях из Q и наоборот.

Внутренние выражения суть F_{O_P} и F_{O_Q}, где O_P — индексы P, нужные
дальше или входящие в O; по предположению индукции они равны результатам
поддеревьев. Внешняя ⊕-сумма по общим невыходным индексам — это в точности
(λ, μ)-произведение с μ-группой из общих невыходных и λ-группой из общих
выходных индексов. ∎

**Следствие 1 (инвариантность к порядку свёрток).** Для любых планов p, p′
выполняется ev_p = ev_{p′}.

*Доказательство.* Оба равны F_O по теореме 1. ∎

Именно следствие 1 делает оптимизацию корректной: выбирая порядок свёрток по
стоимости, оптимизатор не меняет результат. Эмпирическая проверка на всех
18 порядках для четырёхоперандного плана —
`test_every_contraction_order_gives_the_same_result`, расхождение 2.4·10⁻¹⁵.

**Следствие 2 (декомпозиция при превышении лимита индексов).** Если число
различных индексов превышает предел реализации einsum (52), любой план можно
вычислить цепочкой парных произведений с тем же результатом.

*Доказательство.* Двоичное дерево существует для любого n ≥ 1; по теореме 1
его вычисление даёт F_O. ∎

## 4. Класс представимых запросов

**Определение 6 (класс Q_lin).** Запрос принадлежит Q_lin, если он имеет вид

```
SELECT G, agg₁(e₁), …, agg_r(e_r)
FROM   кубы фактов
WHERE  φ
GROUP BY G
```

где

* G — набор измерений, каждое из которых является осью хотя бы одного куба
  либо достижимо из такой оси по цепочке иерархий;
* agg ∈ {SUM, COUNT} (и AVG как их отношение);
* каждое e — выражение из мер, констант, операций +, −, × и деления на
  ненулевую константу;
* φ — произвольная булева комбинация предикатов над значениями измерений и
  их атрибутов.

**Лемма 1 (нормализация выражений).** Всякое выражение e из определения 6
приводится к виду Σ_j α_j · Π_{m ∈ M_j} m, где α_j ∈ ℝ, а M_j — мультимножества
мер.

*Доказательство.* Индукция по структуре e. Константа и мера — базис.
Для e₁ ± e₂ списки слагаемых объединяются (с изменением знака коэффициентов).
Для e₁ × e₂ берётся попарное произведение слагаемых: коэффициенты
перемножаются, мультимножества мер объединяются — это законно по
дистрибутивности × над ±. Деление на константу c ≠ 0 умножает все
коэффициенты на 1/c. ∎ *(Реализация: `amdb.ql.binder.normalize`.)*

**Лемма 2 (фильтр как операнд).** Пусть φ зависит от измерений d₁,…,d_t.
Обозначим χ^φ: I_{d₁}×…×I_{d_t} → {0, 1} индикатор φ. Тогда для любого куба A

```
Σ_{ячейки, удовлетворяющие φ} A  =  Σ_{все ячейки} A · χ^φ
```

*Доказательство.* Слагаемые, не удовлетворяющие φ, умножаются на 0 и не
влияют на сумму; удовлетворяющие умножаются на 1. ∎

Следовательно селекция σ_φ реализуется добавлением χ^φ операндом в то же
стягивание — отдельного прохода по данным не требуется.

**Лемма 3 (иерархия как матрица перехода).** Пусть измерение p достижимо из c
по иерархии, заданной отображением h: I_c → I_p. Положим
H_{c,p} = 1, если h(c) = p, и 0 иначе. Тогда группировка по p равносильна
(0, 1)-произведению с H.

*Доказательство.* (A ∗_{0,1} H)_{…,p} = Σ_c A_{…,c} · H_{c,p} = Σ_{c: h(c)=p} A_{…,c}
— в точности сумма по прообразу p. Для цепочки иерархий h₂ ∘ h₁ матрица
перехода есть матричное произведение H₁ · H₂ (проверка непосредственная). ∎

**Теорема 2 (о представимости).** Всякий запрос из Q_lin представим как
линейная комбинация (λ, μ)-свёрнутых произведений над (ℝ, +, ·).

*Доказательство.* По лемме 1 каждый агрегат распадается на линейную
комбинацию слагаемых вида α · Π m. Для фиксированного слагаемого:
операндами берём кубы, содержащие меры из M_j; по лемме 3 добавляем матрицы
перехода для тех измерений из G, что не являются осями этих кубов; по лемме 2
добавляем индикатор χ^φ. Выходной набор индексов полагаем равным G. По
определению 4 полученное выражение есть F_G, а по теореме 1 оно вычисляется
любым планом как композиция (λ, μ)-произведений. COUNT получается тем же
построением с индикаторным (или счётным) кубом вместо куба меры; AVG — как
отношение двух таких выражений. Линейная комбинация по j завершает
построение. ∎

**Утверждение 3 (о непредставимости MIN/MAX).** Агрегаты MIN и MAX не
представимы никакой линейной комбинацией (λ, μ)-произведений над (ℝ, +, ·)
с фиксированными вспомогательными матрицами.

*Доказательство.* По A3 всякое (λ, μ)-произведение линейно по каждому
операнду, а линейная комбинация таких произведений с фиксированными
вспомогательными матрицами есть линейная функция куба-меры A. Линейная
функция аддитивна: f(A + B) = f(A) + f(B). Возьмём куб ранга 1 длины 2 и
f = max по единственной оси:

```
f((1,0)) + f((0,1)) = 1 + 1 = 2,   но   f((1,0) + (0,1)) = f((1,1)) = 1.
```

Аддитивность нарушена, значит f не линейна и не представима. ∎

Это доказывает, что исключение MIN/MAX из модели — не дефект реализации,
а свойство алгебры над (+, ·).

## 5. Обобщение на полукольца

**Теорема 4.** Все доказательства §2 и §3 используют лишь аксиомы
коммутативного полукольца. Следовательно определение 2 корректно, а
утверждения A1–A9, теорема 1 и следствия 1–2 справедливы над любым
коммутативным полукольцом K.

*Доказательство.* Просмотр доказательств: применялись ассоциативность и
коммутативность ⊕ и ⊗, дистрибутивность ⊗ над ⊕, свойства 0̄ и 1̄, и
конечность множеств индексов. Свойства кольца (существование обратного по ⊕)
не использовались нигде. ∎

**Следствие 3.** MAX-агрегация по группе осей есть (0, μ)-свёрнутое
произведение с матрицей из 1̄ над полукольцом (ℝ≥0, max, ·, 0, 1);
MIN-агрегация — над (ℝ≥0 ∪ {+∞}, min, ·, +∞, 1).

**Утверждение 5 (об области определения).** (ℝ, max, ·) полукольцом **не**
является: дистрибутивность нарушается на отрицательных множителях.

*Доказательство.* max(2, 3)·(−1) = −3, а max(2·(−1), 3·(−1)) = −2. ∎

**Следствие 4 (практическое).** На знакопеременных данных теорема 1 для
(max, ·) неверна, и переписывание плана перестаёт быть корректным: разные
порядки свёрток дают разные ответы. Проверено численно — расхождение
порядка 1.1 при данных единичного масштаба
(`test_max_times_is_a_semiring_only_on_nonnegative_values`).

Поэтому реализация проверяет знак операндов и отклоняет вычисление над
(max, ·) / (min, ·) при отрицательных значениях, если проверка явно не снята
(`amdb.core.semiring.check_domain_of`).

**Утверждение 6.** Тропические полукольца (ℝ ∪ {+∞}, min, +, +∞, 0) и
(ℝ ∪ {−∞}, max, +, −∞, 0) — полукольца на всей числовой оси.

*Доказательство.* min(x, y) + z = min(x + z, y + z) для любого z ∈ ℝ
(сдвиг сохраняет порядок); ассоциативность и коммутативность min и +
очевидны; +∞ — нейтраль min и поглощающий для +; 0 — нейтраль +. ∎

Следовательно над тропическими полукольцами все алгебраические гарантии
сохраняются при любых знаках — проверено
(`test_tropical_semiring_is_associative_on_signed_values`), а классическое
следствие — вычисление кратчайших путей повторным (min, +)-произведением
матрицы смежности (`test_tropical_semiring_computes_shortest_paths`).

## 6. Об изоморфизме моделей

Вопрос об изоморфизме реляционной и многомерно-матричной моделей в
формулировке ТЗ остаётся без доказательства (и, судя по доступной литературе,
без доказательства в первоисточниках). Однако **точное условие, при котором
изоморфизм имеет место, доказывается легко** — и это конструктивная замена
недоказанному тезису.

**Определение 7 (отображение отношения в гиперкуб).** Пусть R —
мультимножество кортежей, π: R → V_{d₁} × … × V_{d_p} — проекция на набор
измерений, m: R → K — мера. Положим

> φ(R)[x] = ⊕_{r ∈ π⁻¹(x)} m(r)

— ячейка есть ⊕-сумма меры по слою (прообразу точки); в терминах теории меры
это прямой образ меры m вдоль π.

**Утверждение 7 (гомоморфность).** φ(R ⊎ R′) = φ(R) ⊕ φ(R′), где ⊎ —
мультимножественное объединение.

*Доказательство.* π⁻¹(x) для R ⊎ R′ есть дизъюнктное объединение слоёв R и R′,
а ⊕-сумма по дизъюнктному объединению равна ⊕-сумме частичных сумм
(ассоциативность и коммутативность ⊕). ∎

**Теорема 5 (условие изоморфизма).** Ограничение φ на отношения с ненулевыми
мерами инъективно тогда и только тогда, когда π инъективно на R — то есть
набор измерений (d₁, …, d_p) является **ключом** отношения фактов.

*Доказательство.*

(⇐) Пусть π инъективно. Тогда каждый слой π⁻¹(x) содержит не более одного
кортежа, и φ(R)[x] = m(r) для единственного r с π(r) = x, либо 0̄, если слой
пуст. Значит по φ(R) восстанавливается множество кортежей (ненулевые ячейки) и
их меры — φ обратимо на своём образе.

(⇒) Пусть π(r₁) = π(r₂) = x для различных r₁ ≠ r₂. Возьмём R с мерами
m(r₁) = a, m(r₂) = b и R′ с мерами m′(r₁) = a′, m′(r₂) = b′, где
a ⊕ b = a′ ⊕ b′, но (a, b) ≠ (a′, b′) (в K = ℝ такие пары существуют всегда
при a ⊕ b ≠ 0). Тогда R ≠ R′, но φ(R) = φ(R′), то есть φ не инъективно. ∎

**Следствие 5.1.** В общем случае φ — сюръективный гомоморфизм, но **не**
изоморфизм. Изоморфизм на уровне экземпляров имеет место в точности тогда,
когда гранулярность гиперкуба совпадает с гранулярностью отношения.

**Следствие 5.2 (гранулярность MIN/MAX).** Если слой содержит более одного
кортежа, max по ячейкам не равен max по кортежам: слой схлопывается ⊕-суммой,
и информация о его составе теряется. Пример: меры 3 и 5 в одном слое, 4 в
другом дают куб {8, 4}; максимум по кубу 8, по кортежам 5.

Это объясняет расхождение, обнаруженное в реализации эмпирически, как
**следствие свойств отображения**, а не как дефект.

**Следствие 5.3 (счётный куб).** Пара (φ_sum(R), φ_count(R)), где φ_count
строится по мере ≡ 1̄, различает больше, чем φ_sum: она сохраняет мощность
каждого слоя. Поэтому COUNT и AVG в реализации точны. Полным инвариантом
пара не является: распределение меры внутри слоя ею не восстанавливается.

*Проверка:* `test_mapping_is_injective_when_dimensions_form_a_key`,
`test_mapping_is_not_injective_when_dimensions_are_not_a_key`,
`test_mapping_is_a_homomorphism_for_sum`, `test_count_cube_is_a_finer_invariant`.

## 7. Что осталось недоказанным

| Утверждение | Состояние |
|---|---|
| Изоморфизм реляционной и многомерно-матричной моделей **в общем случае** | Опровергнут: теорема 5 даёт точное условие (измерения образуют ключ), вне которого изоморфизма нет |
| Изоморфизм **алгебр операций** (а не экземпляров) | Не доказан ни здесь, ни, судя по доступной литературе, в первоисточниках |
| Полнота: транслятор покрывает **ровно** Q_lin | Доказана одна сторона (теорема 2). Обратное включение следует из конструкции связывателя, но формально не выписано |
| Соответствие определения 2 оригиналу Соколова (1972) | Не проверено: книга недоступна |
| Теория квадратных многомерных матриц (определитель, обращение) | Не рассматривается: для OLAP не нужна |

**О статусе изоморфизма.** Поиск по открытым источникам показал, что в
доступной работе Мунермана В.И. и Мунермана Д.В. «Алгебраический подход к
построению программно-аппаратных комплексов…» (2015) соответствие между
реляционной и многомерно-матричной моделями характеризуется как то, которое
«может быть установлено» — как гомоморфное либо изоморфное, — **без
доказательства**. Формулировка технического задания («Доказан изоморфизм…»)
таким образом первоисточником не подтверждается и требует проверки по
работам, которые в открытом доступе найти не удалось. Подробнее —
[аудит концепции машины](Соответствие%20концепции%20алгебраической%20машины.md), §5.

Что даёт настоящий документ вместо недоказанного тезиса:

* **теорему 5** — точное условие, при котором отображение моделей обратимо
  (измерения образуют ключ отношения фактов), и доказательство того, что вне
  этого условия изоморфизма нет;
* **теорему 2** — конструктивное описание класса запросов, представимых
  свёрнутыми произведениями;
* **утверждение 3** — доказательство того, что́ лежит вне этого класса и почему.

Для обоснования корректности транслятора этого достаточно. Для утверждения
об изоморфизме **алгебр операций** (реляционной алгебры и алгебры многомерных
матриц как систем, а не отдельных экземпляров) — нет: такое утверждение
требует построения взаимно обратных функторов, чего здесь не делается.
